# Evidence

## M1

The M1 physical-part evidence supplied for this repository consists of three enclosure viewpoints.

Files:
- `m1/printed_part_view_1.jpg`
- `m1/printed_part_view_2.jpg`
- `m1/printed_part_view_3.jpg`

These images demonstrate the physical enclosure appearance and multiple viewpoints.

They do **not** establish Raspberry Pi FPS, latency or confidence because the supplied images explicitly identify those values as illustrative/mockup values.

## M2

The M2 benchmark evidence is generated by:

```bash
BENCHMARK_FRAMES=100 python scripts/benchmark.py
```

The resulting `data/measurements/benchmark.csv` should be committed after running on the target Raspberry Pi.
